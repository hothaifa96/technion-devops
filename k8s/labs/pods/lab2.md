# Lab: Create a Multi-Container Pod in Kubernetes

## Objective

In this lab you will learn how to:

- Create a Pod with **two containers**
- Configure **environment variables**
- Expose **container ports**
- Verify both containers are running
- Test connectivity inside the Pod

---
# so ....

Your company is building a simple web application.

The application consists of:

1. **Frontend**
   - Uses the ''[resume-m](https://hub.docker.com/r/hothaifaz11/resume-m/tags)'' image
   - Listens on port **3000**

2. **Backend**
   - Uses the `traefik/whoami` image
   - [see link](https://hub.docker.com/r/traefik/whoami)
   - returns a simple message with information about the request and the ip 
   - Listens on port **80**

Both containers should run inside the **same Pod**.

---

# Requirements

Create a Pod named:

```bash
webapp-pod
```

The Pod should contain **two containers**.

Name:
